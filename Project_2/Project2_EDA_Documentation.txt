7. PHASE 3: OUTLIER DETECTION
================================================================================

METHOD COMPARISON: IQR vs Z-Score

┌─────────────────┬─────────────────────────────────────────────┐
│ IQR Method      │ Z-Score Method                              │
├─────────────────┼─────────────────────────────────────────────┤
│ Robust against  │ Sensitive to extreme values                 │
│ extreme values  │                                             │
├─────────────────┼─────────────────────────────────────────────┤
│ Best for:       │ Best for:                                   │
│ 'Dirty' business│ Normal distributions                        │
│ data            │                                             │
├─────────────────┼─────────────────────────────────────────────┤
│ Formula:        │ Formula:                                    │
│ Outlier < Q1 -  │ Z = (Value - Mean) / Std                    │
│ 1.5×IQR         │ Flag if |Z| > 3                             │
│ or > Q3 + 1.5×IQR│                                            │
├─────────────────┼─────────────────────────────────────────────┤
│ Result: 0       │ Result: 0                                   │
│ outliers        │ outliers                                    │
└─────────────────┴─────────────────────────────────────────────┘

DECISION: IQR Method selected for business data

IQR CALCULATION (TotalPrice):
  Q1: $440.19
  Q3: $1,507.31
  IQR: $1,067.12
  Lower Bound: $440.19 - 1.5×$1,067.12 = -$1,160.49 (not applicable, no negative prices)
  Upper Bound: $1,507.31 + 1.5×$1,067.12 = $3,107.99

OUTLIERS DETECTED: 0
  All high-value orders are mathematically valid (Quantity × UnitPrice = TotalPrice)
  → These are SIGNAL (legitimate bulk/VIP orders), not NOISE

FORENSIC NOTE:
  "Noise = Data entry mistakes, typos. Action: Clean/Remove."
  "Signal = Fraud, VIP customers, rare events. Action: Investigate."
  In this dataset: All extreme values are signal. No cleaning required.

KEY CORRELATIONS:
  • UnitPrice ↔ TotalPrice:   r = 0.717 (Strong positive)
    → Higher unit prices strongly drive order totals
  • Quantity ↔ TotalPrice:    r = 0.615 (Moderate positive)
    → More units = higher totals, but not as strong as price
  • ItemsInCart ↔ TotalPrice: r = 0.285 (Weak positive)
    → Cart size has minimal impact on final price
  • Quantity ↔ ItemsInCart:   r = 0.287 (Weak positive)
    → Cart browsing doesn't always convert to purchase quantity

FORENSIC NOTE:
  "A correlation is a CLUE, not a VERDICT. Always check for hidden variables."
  Example: Ice cream sales correlate with shark attacks (confounder = temperature)
  Here: UnitPrice drives TotalPrice, but Product category may be the hidden variable.

11. KEY LEARNINGS & BEST PRACTICES
================================================================================

1. CHOOSE THE RIGHT OUTLIER METHOD
   IQR for business data (robust, handles skew). Z-Score for normal distributions.
   Wrong choice = false positives = bad decisions.

2. CORRELATION ≠ CAUSATION
   UnitPrice correlates with TotalPrice, but Product category may be the driver.
   Always ask: "What hidden variable explains this relationship?"

3. THE "SO WHAT?" TEST
   "Mean churn increased by 3%" → "We lost 1,510 customers = 11 stores closed."
   Translate numbers to business impact. That's what executives pay for.

4. MEDIAN > MEAN FOR SKEWED DATA
   Mean is pulled by outliers. Median represents the "typical" customer.
   Report both, but lead with median for skewed metrics.

5. VISUAL EVIDENCE MATTERS
   "Cut the noise. Highlight the insight. Remove 3D effects." — DecodeLabs
   Clean charts = clear decisions.
